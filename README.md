# Martin Vizcaino

Software and robotics engineer. CS at the University of Indianapolis (May 2027). I build real-time systems, full-stack products and AI tools, and I measure what I ship.

### Featured

- **[qnx-vibguard](https://github.com/veldig/qnx-vibguard)**: real-time vibration guard for a SCARA robot on QNX 8.0, in C. 200 Hz closed loop that cut vibration 84% on a simulated joint, and kept 0 of 6,000 samples late under full CPU load. QNX Global Hackathon 2026. [Demo video](https://youtu.be/yqareKb2Qn8) · [Devpost](https://devpost.com/software/vibguard-real-time-vibration-guard-for-a-scara-robot)
- **[ruckig-qnx](https://github.com/veldig/ruckig-qnx)**: ported Ruckig (jerk-limited robot motion planning, C++) to QNX 8.0. Full test suite passes on QNX (14/14 cases, 1.44M assertions), builds for x86_64 and aarch64. [Demo video](https://youtu.be/jr_Fj3NRpuk)
- **[nport-reconciler](https://github.com/veldig/nport-reconciler)**: reconciles an ETF's N-PORT holdings from SEC EDGAR between filing periods, with an exception review queue and append-only audit log. Next.js, Drizzle, Postgres.
- **[arm-sort](https://github.com/veldig/arm-sort)**: robot-arm sorting puzzle in Unity with analytic inverse kinematics. Plays in the browser.
